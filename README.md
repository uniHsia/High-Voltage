# 高电压设备智能健康管理一体化平台

## 📋 项目简介

这是一个基于 **Django + PyTorch + ECharts** 的高压电力设备智能健康管理平台，集成了两个核心AI模型：

- **智能诊断模型** - 基于交叉注意力机制的局部放电类型识别
- **健康评估模型** - 改进交叉注意力机制的设备健康指数(HI)和剩余使用寿命(RUL)预测

## ✨ 核心功能

### 🔍 智能诊断
- PRPD相位-幅值分布图谱可视化
- 5种放电类型自动识别（电晕、内部、沿面、悬浮、正常）
- 置信度评估和严重程度判断
- 特征重要性分析
- 历史相似案例检索

### 📊 健康评估
- HI健康指数评分（0-100分）
- 四级健康状态评估（良好/注意/警告/严重）
- RUL剩余使用寿命预测
- 多传感器数据融合趋势
- 异常检测得分历史
- 置信区间预测

### 📈 历史追溯
- 多维度数据查询（设备/类型/时间）
- 历史趋势对比图表
- 诊断记录详细列表
- 报告生成和导出（PDF/Word格式）

### 🏠 实时监控
- 设备总览和状态切换
- 实时波形和PRPD趋势
- 告警信息滚动显示

## 🚀 快速开始

### 环境要求
- Python 3.8+
- 4GB+ RAM
- 推荐使用GPU加速（可选）

### 安装步骤

1. **进入项目目录**
```bash
cd D:\PROJECT\High-Voltage-main\compitition
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **初始化数据库**
```bash
python manage.py makemigrations
python manage.py migrate
python init_db.py
```

4. **启动服务器**
```bash
python manage.py runserver
```

5. **访问系统**
打开浏览器访问：`http://127.0.0.1:8000/`

## 💡 使用指南

### 智能诊断流程
1. 登录系统后，点击侧边栏"智能诊断"
2. 点击"运行诊断模型"按钮
3. 等待模型运行（首次30-60秒，后续10-30秒）
4. 查看诊断结果和可视化图表

### 健康评估流程
1. 点击侧边栏"健康评估"
2. 点击"运行健康评估模型"按钮
3. 等待模型运行（首次1-2分钟，后续20-60秒）
4. 查看健康指数、RUL预测和相关图表

### 设备切换功能
1. 在首页"设备列表"中点击任意设备
2. 系统会记住您的选择
3. 切换到其他页面后再返回，设备选择会保持不变
4. 支持单选模式，点击即选中

### 历史数据查询
1. 进入"历史追溯"页面
2. 选择筛选条件（设备、数据类型、时间范围）
3. 点击"查询"按钮
4. 可生成报告或导出数据

## 🔧 配置说明

### 数据库配置
默认使用SQLite。如需使用其他数据库，修改 `high_voltage_platform/settings.py`:

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'your_database_name',
        'USER': 'your_username',
        'PASSWORD': 'your_password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```

### 静态文件配置
生产环境需要配置静态文件服务：

```bash
python manage.py collectstatic
```
